# 📋 Gestor de Tarefas em Python

## 📖 Descrição

Este projeto consiste no desenvolvimento de um **Gestor de Tarefas** desenvolvido em **Python**.

A aplicação permite ao utilizador criar, consultar, atualizar e eliminar tarefas, facilitando a organização das atividades a realizar.

O projeto utiliza um ambiente virtual **`venv`**, permitindo manter as dependências do projeto isoladas do ambiente global do computador.

---

## 🚀 Tecnologias utilizadas

* **Python 3**
* **venv** — ambiente virtual Python
* **pip** — gestor de pacotes
* 
---

## 🎯 Objetivos

O objetivo deste projeto é desenvolver uma aplicação simples para gestão de tarefas, aplicando conceitos fundamentais de programação em Python.

A aplicação permite:

* ➕ Criar tarefas;
* 📋 Listar tarefas;
* ✏️ Alterar tarefas;
* 🗑️ Eliminar tarefas;
